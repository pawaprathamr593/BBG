# BBG product and users

## Product

BBG helps people discover businesses and products, and helps business owners run a workspace (catalogue, storefront, promotions, customers, subscriptions) on one platform.

## Primary personas

| Persona | Device bias | Goals |
| --- | --- | --- |
| Marketplace visitor | Phone-first | Search businesses/products, open storefronts, browse promotions |
| Customer (signed in) | Phone / desktop | Account, addresses, orders/enquiries history via workspace “My Account” |
| Business owner / staff | Tablet / desktop | Catalogue, storefront, promotions, customers, subscriptions |
| Platform admin | Desktop | Approvals, categories, moderation, payment QR, health |

## UX expectations

- Mobile-first layouts; test ~360–390px plus tablet/desktop
- Light and dark themes using existing CSS tokens
- Clear loading / empty / error / success states
- Keyboard-accessible controls with visible focus
- Destructive actions confirmed; never show success on failure

## Out of scope for agent invention

Do not invent new personas, permission codes, subscription plans, payment flows or marketplace ranking rules. Confirm with the user or existing backend docs.
