# Frontend requirements

Place BBG frontend work contracts here:

```text
requirements/<area>/REQ-<AREA>-<NNN>-<slug>.md
```

Areas: `marketplace`, `storefront`, `auth`, `workspace`, `catalogue`, `shared`.

Use the template from `.agent/skills/requirement-intake/references/requirement-template.md`.
Follow `.agent/workflows/check-requirement.md` and `.agent/workflows/implement-requirement.md`.
