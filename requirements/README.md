# BBG Dashboard Requirements

This folder contains the authoritative dashboard-wide UI/UX and functionality requirements for Antigravity.

- BBG_DASHBOARD_MODULE_UX_RBAC_SUBSCRIPTION_SPEC.md — detailed requirements, source-of-truth rules, UX/data presentation, business approval, plans/entitlements, Team & Access, security, componentisation and acceptance criteria.
- ANTIGRAVITY_IMPLEMENTATION_PROMPT.md — execution prompt. It requires Antigravity to read the specification and existing .agent rules/skills before implementation.

From the repository root, provide Antigravity with ANTIGRAVITY_IMPLEMENTATION_PROMPT.md. The prompt references the full specification in this folder.

These documents supplement, and do not replace, existing repository rules, .agent skills, architecture documentation or verified API/database contracts.
